# 🎯 Quiz Game

An interactive multiple-choice quiz game that supports various question types like single-select, multi-select, and fill-in-the-blanks.

## 🚀 Features

- Multiple-choice, single-select, and multi-select questions  
- Fill-in-the-blanks support  
- Instant feedback and final score
  

## 🎮 How to Play

1. Answer the questions.  
2. Submit your response.  
3. View your final score!
